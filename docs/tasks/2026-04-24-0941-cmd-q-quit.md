# Cmd+Q Quit Fix

## What Was Done

- Investigated the Electrobun application menu in `src/bun/index.ts`.
- Confirmed the app relied on the built-in `{ role: "quit" }` menu item.
- Replaced the built-in quit role with an explicit `app:quit` application-menu action using the `Command+Q` accelerator.
- Routed `app:quit` through `process.exit(0)`, which Electrobun overrides to run its native quit sequence.

## Root Cause

Electrobun exposes menu roles and labels, but this app was relying on the runtime's `quit` role to both advertise and handle the macOS quit shortcut. The local Electrobun API supports explicit accelerators and custom application-menu actions, and those are already used for update actions in this app. Wiring quit through the same path makes Cmd+Q deterministic for the shipped desktop runtime.
